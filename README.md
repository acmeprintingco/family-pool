# Family Pick It

A standalone family betting pool: game odds, pick'em, prop bets, head-to-head challenges, playoff bracket and standings.
Data lives in the Supabase project `family-pool`. Static site, no build step.

## Deploy on Vercel
1. Put these files in a GitHub repo (or drag the folder into a new Vercel project).
2. In Vercel: Add New → Project → import the repo → Framework preset: **Other** → Deploy.
3. Open the URL on each phone and use Share → Add to Home Screen.
